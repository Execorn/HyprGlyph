# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in HyprGlyph (such as arbitrary command execution during configuration parsing or unsafe file writes), please report it responsibly:

1. **Do not** create a public GitHub issue.
2. Send an email to the repository maintainer via GitHub profile contact or open a private security advisory through the GitHub repository security tab.
3. Include details of the vulnerability, reproduction steps or sample configuration snippet, and potential impact.

Maintainers will acknowledge receipt within 48 hours and coordinate a fix release.
